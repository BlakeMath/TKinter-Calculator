# Tkinter Calculator

A simple calculator desktop app built with Python and `tkinter`.

## Features

- Number buttons (`0`-`9`)
- Addition operation (`+`)
- Equal operation (`=`)
- Clear button to reset input

## Requirements

- Python 3.x
- `tkinter` (usually included with standard Python installations)

## Run the Calculator

1. Open a terminal.
2. Navigate to the cloned project directory:
   ```bash
   cd TKinter-Calculator
   ```
3. Run the app:
   ```bash
   python "tkinter Calculator.py"
   ```

## Project Structure

- `tkinter Calculator.py` - main calculator application

## Current Limitations

- Currently supports only addition.
- Input is handled as integers.
